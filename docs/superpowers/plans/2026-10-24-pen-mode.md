# План: режимы «Стандарт» и «Ручка»

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** вкладки «Стандарт» / «Ручка» на экране тренировки; в «Ручке» вся тренировка — текст, при переключении карточки ↔ текст преобразуются друг в друга; шторка быстрой записи удаляется.

**Architecture:** чистая сериализация карточек в текст (`src/domain/pen/`), чистое восстановление карточек из разобранных строк (`src/store/activeWorkoutPen.ts`), режим и текст в сторе активной тренировки, экран ветвится по режиму. Разбор и подбор упражнений — существующий `src/domain/quickEntry/`.

**Tech Stack:** TypeScript 6, React Native 0.88 / Expo 58, zustand 5, jest.

**Spec:** `docs/superpowers/specs/2026-10-24-pen-mode-design.md`

## Global Constraints

- AGENTS.md: полные имена, комментарии на русском, файлы ≲ 250 строк (active.tsx уже больше — не раздувать: новое выносить в `src/features/workout/pen/`), нет вложенных тернарников.
- Строки интерфейса в `workout` обоих словарей.
- Коммиты делает владелец; задача заканчивается `npm run format` и названием коммита.
- Финал: `npm run format && npm run typecheck && npm run lint && npm test`, grep-проверка ключей переводов.

## Review Focus

1. Круг Стандарт → Ручка → Стандарт не теряет значения, типы, RIR, порядок и `completedAt` выполненных подходов — тест в Задаче 2.
2. Текст с ошибкой не даёт переключиться и не теряет строки; пустой текст спрашивает подтверждение — Задача 4 (ручная проверка).
3. Старое хранилище без `entryMode`/`penText` открывается в «Стандарте» с пустым текстом — тест `merge` в Задаче 3 через `normalizeActiveWorkout`? нет: `merge` даёт значения по умолчанию; проверить типами и вручную.
4. Завершение из «Ручки» с ошибками в тексте не сохраняет тренировку — Задача 4.
5. Сериализация `assisted_bodyweight` даёт `-20кг х 8`, а `weighted_bodyweight` — `+10кг х 8`, и оба разбираются обратно — тест в Задаче 1.

Группировка по весу подряд — своя (не `groupSets`, тот форматирует для чтения).

- [ ] Тесты: `weight_reps` подходы 70×9(1), 70×8(1) warmup-нет, 80×5 failure → `'Приседания со штангой 70кг х 9(1)/8(1), 80кг х 5о'`; `bodyweight_reps` 12/10 → `'Подтягивания 12/10'`; `weighted_bodyweight` +10 → `'Подтягивания с отягощением +10кг х 8'`; `assisted_bodyweight` 20 → `'Подтягивания в гравитроне -20кг х 8'`; `duration` 60/45 → `'Планка 1:00/0:45'`; `distance_duration` 5000 м + 1500 с → `'Бег 5км 25:00'`; пустые подходы пропускаются, карточка без значений → только имя; `language: 'en'` → суффикс `f`; `lb` → `'154.3lb'`; `serializeWorkout` соединяет строки `\n`.

**Files:** Create `src/features/workout/pen/PenEditor.tsx`, `src/features/workout/pen/usePenText.ts` (перенос `useQuickEntry.ts`), `src/features/workout/pen/applyPenText.ts`; Modify `src/app/workout/active.tsx`; Delete `src/features/workout/quickEntry/AddExerciseButtons.tsx`, `QuickEntrySheet.tsx`, `QuickEntryPreview.tsx`, `quickEntryToastMessage.ts`, `useQuickEntry.ts`; переместить `commitQuickEntry.ts` в `pen/`. i18n: новые ключи и удаление неиспользуемых (список в спеке).

**Interfaces:**
```ts
// applyPenText.ts
export type ApplyPenTextResult = { ok: true; exercises: ActiveExercise[] } | { ok: false; errorLineCount: number };
export function applyPenText(text: string, workout: ActiveWorkout, candidates: PreparedCandidate[], typeByExerciseId: Map<string, ExerciseType>, distanceUnit: DistanceUnit, now: number): ApplyPenTextResult;

```
- `PenEditor` использует `usePenText` для статуса и ошибок; кандидаты из него же нужны `applyPenText` — хук возвращает `candidates` и `typeByExerciseId`, экран держит их через `usePenText` только когда режим «Ручка» (компонент `PenEditor` монтируется только в этом режиме, а применение вызывается из него через `onApply` колбэк? — нет: проще экран сам вызывает `usePenText(penText, exerciseIds)` всегда: запросы к базе мемоизированы `useQuery`, а разбор пустого текста бесплатный).
- Переключение: Стандарт → Ручка: `switchToPen(serializeWorkout(workout, options))`. Ручка → Стандарт: `applyPenText` → при `ok` `applyPenResult(exercises)`, иначе `toast(penFixErrors)`; пустой текст при наличии карточек — `confirm(penClearConfirm)`.
- Завершение: в `finishWorkout`, если режим «Ручка», сначала применить текст; при ошибке — тост и выход; дальше работать с обновлённым `getWorkoutStore().workout`.
- Кнопка таймера: `RestTimerPickerSheet` c `sheet.kind === 'penRest'`, `selectedSeconds = null`, `onRestSelect(seconds)` → `startRest(seconds ?? settings.defaultRestSeconds)`.
- Кнопка «+ Добавить упражнение» — как в коммите до быстрой записи (`Button` с `Plus`, `fullWidth`, `primary` пока нет упражнений).
