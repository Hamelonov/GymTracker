# Два режима записи тренировки: «Стандарт» и «Ручка»

Дата: 2026-10-24. Статус: согласовано с владельцем в чате. Заменяет шторку быстрой записи из
`2026-10-24-quick-entry-design.md`; грамматика строки оттуда остаётся без изменений.

## Зачем

Быстрая запись текстом оказалась удобнее как отдельный режим, а не как шторка: владелец хочет либо
нажимать кнопки в карточках («Стандарт»), либо вести всю тренировку одним текстом («Ручка») и
переключаться между ними в любой момент — текст превращается в карточки и обратно.

## Как это выглядит

- Под шапкой и блоком статистики экрана активной тренировки — **вкладки** `Segmented` с иконками:
  «Стандарт» (`LayoutList`) и «Ручка» (`PenLine`). Режим хранится вместе с активной тренировкой и
  переживает перезапуск приложения.
- **Стандарт** — как до быстрой записи: карточки упражнений и одна широкая кнопка
  «+ Добавить упражнение» (жёлтая, пока упражнений нет). Шторка быстрой записи и ряд из двух кнопок
  удаляются.
- **Ручка** — вместо карточек одно многострочное поле на всю страницу (растёт с текстом, минимум
  ~240 px), по упражнению на строку, плейсхолдер `Присед со штангой 70кг х 9(1)/8(1)/8(0)`.
  Под полем:
  - строка состояния «5 упражнений · 14 подходов» (считается по разобранным строкам);
  - список строк с ошибками: исходный текст строки и подсказка (как в предпросмотре быстрой записи);
  - кнопка **«Таймер отдыха»** (`Timer`): открывает уже существующую шторку выбора времени
    (`RestTimerPickerSheet`), выбор сразу запускает таймер на это время. Автоматически таймер в
    «Ручке» не стартует.
- Переход **Стандарт → Ручка**: карточки сериализуются в текст (см. ниже). Если текст «Ручки» уже
  есть (режим менялся туда-сюда), он перезаписывается свежей сериализацией карточек: источник истины —
  тот режим, из которого уходим.
- Переход **Ручка → Стандарт**: текст применяется к тренировке. Если в тексте есть строки с ошибками,
  переход не происходит, показывается тост «Исправьте строки с ошибками» и ошибки остаются
  подсвеченными. Пустой текст применяется как «ни одного упражнения» (все карточки удаляются) —
  перед этим `confirm`, если карточки были.
- **Завершение тренировки** из «Ручки»: нажатие «Завершить» в шапке сначала применяет текст (те же
  правила и та же блокировка при ошибках) и переводит экран в «Стандарт», затем открывается обычная
  шторка завершения с верной статистикой. Пока текст не применён, счётчики упражнений и подходов в
  статистике и доступность кнопки «Завершить» считаются по разобранному тексту.
- При редактировании сохранённой тренировки (`session.mode === 'edit'`) вкладок нет: только «Стандарт».
- `startEmpty`, `startFromRoutine`, `startFromActive` и `clear` сбрасывают режим в «Стандарт» и текст.

## Сериализация карточек в текст

Одна карточка — одна строка: `<название> <подходы>`.

- Название — отображаемое имя упражнения (`exerciseName`, язык интерфейса).
- В текст попадают **только выполненные** подходы, сгруппированные подряд по весу: `70кг х 9(1)/8(1), 80кг х 5`.
  Невыполненные подходы (план из программы, пустые строки, «Повторить тренировку») в текст не попадают и
  остаются за ним; карточка без выполненных подходов — одно название.
- Вес пишется в единице из настроек с единицей, которую понимает парсер: `кг` / `lb` (не локализованная
  подпись «фунт»); дробь через точку (`72.5кг`).
- Упражнения со своим весом: только повторы (`12/10/8`); с дополнительным весом — `+10кг х 8`;
  с помощью (`assisted_bodyweight`) — `-20кг х 8`.
- Время — `1:00` (часы — `1:02:30`), дистанция — `5км` / `3mi` (с десятичной точкой), вместе —
  `5км 25:00`.
- Тип подхода — суффикс после повторов: `р`/`о`/`д` в русском интерфейсе, `w`/`f`/`d` в английском.
  RIR — `(1)` после повторов (и после суффикса типа, если он есть). RPE в текст не попадает и при
  обратном преобразовании сохраняется у подходов, которые остались на месте (см. ниже).
- Парсер уже принимает всё перечисленное; `ми` (русская подпись миль) добавляется в токенизатор.
- Название с цифрой внутри (`Тяга 21`) отделяется от подходов двоеточием: `Тяга 21: 70кг х 8`; парсер
  принимает двоеточие после названия в любой строке (двоеточие внутри времени `1:00` не считается).
- Выполненный подход с весом без повторов пишется одним весом (`70кг`); подход без веса после подхода
  с весом — с явным нулём (`+0кг х 10`), который при применении снова становится «без веса».
- Тип подхода у времени и дистанции — тем же суффиксом после значения: `0:45р`.
- В английском интерфейсе знак умножения — латинская `x`.

## Применение текста к тренировке

Чистая функция `rebuildWorkoutFromLines(workout, commits, lastPerformanceByExerciseId, now)`:

1. Упражнения получаются в порядке строк; `commits` приходят из существующего `commitQuickEntry`
   (он же создаёт новые упражнения в библиотеке).
2. Строка с упражнением, у которого уже есть карточка (по `exerciseId`; первая найденная), сохраняет
   её `id`, заметку, отдых, суперсет и `extraFields` (объединённые с полями из строки).
3. Новые подходы карточки = подходы из строки **(все `completed: true`)** + оставшиеся невыполненные
   подходы старой карточки после них. Подход из строки на позиции `i` берёт `id`, `completedAt`,
   `previous` и `rpe` выполненного старого подхода на позиции `i`, если тот есть; иначе занимает
   очередной невыполненный подход карточки (его `id` и `previous`, `completedAt = now`); иначе `id`
   новый, `completedAt = now`, `previous` — из последнего выполнения по индексу. Если вес из текста
   совпадает со старым с точностью до 0,01 кг, остаётся старый `weightKg` (круг в фунтах не сдвигает вес).
4. Карточки, которых нет в тексте, удаляются. Две строки одного упражнения — одна карточка,
   подходы подряд.
5. Строка «только название» для существующей карточки оставляет её невыполненные подходы и убирает
   выполненные (так написано — так и есть); для новой — карточка с пустыми подходами из прошлого раза.
6. Подбор упражнения: точное совпадение названия (после нормализации) побеждает нечёткое, иначе карточка
   могла бы «переехать» на похожее упражнение и потерять заметку и отдых.

Круговая проверка (тест): сериализация тренировки → разбор → применение даёт те же значения
подходов, типы, RIR и порядок; выполненные остаются выполненными с прежними `completedAt`.

## Данные

- Стор активной тренировки: `entryMode: 'standard' | 'pen'` и `penText: string`, оба в `partialize`.
  Действия: `setPenText`, `switchToPen(text)` (текст сериализует экран — ему доступны названия и
  единицы), `applyPenResult(exercises)` + `switchToStandard()`. `clear()` сбрасывает режим в
  «Стандарт» и текст в пустую строку.
- `normalizeActiveWorkout` не меняется; отсутствующие `entryMode`/`penText` в старом хранилище
  закрываются значениями по умолчанию в `merge`.
- База не меняется.

Строки интерфейса (`workout.*`): `modeStandard` «Стандарт»/«Standard», `modePen` «Ручка»/«Pen»,
`penPlaceholder`, `penSummary` с плюралями («{{exercises}} · {{sets}}» из существующих
`home.exercisesCount` и `quickEntrySets`), `penFixErrors` «Исправьте строки с ошибками»/«Fix the
lines with errors», `penClearConfirm` «Текст пустой. Удалить все упражнения из тренировки?»/«The text
is empty. Remove all exercises from this workout?». Ключи шторки быстрой записи, которые больше не
используются (`quickEntryTitle`, `quickEntryPlaceholder`, `quickEntryHint`, `quickEntryAdded*`,
`addExerciseFromList`), удаляются; `quickEntryNewExercise`, `quickEntryError*`, `quickEntrySets`
остаются.

## Не делаем сейчас

- Автозапуск таймера в «Ручке», подсветка синтаксиса, автодополнение названий.
- Режим «Ручка» в редакторе программ.

## Решения, принятые мной

- Источник истины — режим, из которого уходим; текст «Ручки» перезаписывается при каждом входе.
- Все подходы из текста считаются выполненными; заполненный, но не отмеченный подход из «Стандарта»
  после круга станет выполненным. Это цена простоты записи.
- При ошибках в тексте переключение и завершение блокируются, а не теряют строки.
- Кнопка таймера в «Ручке» запускает таймер сразу по выбору времени, «по умолчанию» — значение из настроек.
